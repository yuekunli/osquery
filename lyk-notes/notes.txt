launch.json (VS Code launch settings)
settings.json (VS Code workspace settings, containing cmake related settings)
c_cpp_properties.json (VS Code c/c++ compiler settings)

Note that if I want to work with this project on another computer and if I want to use just VS Code (with Visual Studio installed on that computer).
